# 知网论文检索 Plugin — 0.3.1

可迁移的只读论文研究插件，包含通用插件清单、MCP服务配置、Python服务及检索技能。技能采用能力检测，不依赖特定宿主或浏览器产品名称。

## 工具

1. `search_papers`：按主题、标题或作者检索知网公开可见元数据，支持年份和结果数量限制。
2. `get_paper`：读取知网详情页可访问的元数据和摘要。
3. `search_public_sources`：在知网和浏览器不可用时检索Crossref、OpenAlex，保留数据来源及引用量口径。

## 检索流程

知网直连 → 宿主已授权浏览器 → 公开学术API → 宿主可用的公开网页检索。后续层级只在需要时执行；浏览器控制与网页检索由宿主提供，插件本身不内置这些驱动。登录、机构认证及验证码必须由用户完成。

## 固定四部分输出

1. 检索说明：两列表格及核验数量汇总。
2. 检索结果：八列主表及可点击论文标题。
3. 单篇论文解读：固定卡片，详细元数据、来源、内容解读、证据声明及完整GB/T 7714引用。
4. 跨论文综合：主题对比矩阵、共识、分歧、研究空白、建议及优先阅读推荐。

无结果或证据不足时保留四部分标题并说明原因，不编造论文或结论。不新增第五部分，完整引用仍留在每篇卡片底部。具体格式以 `skills/cnki-paper-research/references/output-schema.md` 为准。

## 迁移与运行

使用Python 3.10或更高版本运行 `server/cnki_mcp.py`。将 `mcp.json` 中的 `${PLUGIN_ROOT}` 解析为当前插件根目录，并加载技能及其引用文件。仅接入MCP工具不会自动应用四部分输出指令。

`plugin.json` 的 `org.cnki-paper-research` 扩展包含 `skills`、`mcpServers` 和 `interface`。不同宿主可能需要适配这些字段及本地目录清单；不保证所有宿主都能识别同一安装包。

本插件不绕过访问控制，不批量下载全文，不读取或暴露凭据。网络访问失败时报告失败并尝试授权范围内的降级来源，不关闭证书校验。
