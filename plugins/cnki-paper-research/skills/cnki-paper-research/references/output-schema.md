# Output schema — 0.3.1

默认使用中文 Markdown。严格按以下四部分及顺序输出；不得新增第五部分“参考文献与数据来源”。以下占位符仅说明格式，实际输出必须替换成可核验数据或规定的缺失标记。

目录：[检索说明](#一检索说明) · [检索结果](#二检索结果) · [单篇论文解读](#三单篇论文解读) · [跨论文综合](#四跨论文综合)

## 一、检索说明

使用两列表格，按以下顺序填写。数据通道只记录实际执行的层级、结果和跳过原因，不把计划或不可用能力写成已执行。

| 项目 | 内容 |
|---|---|
| 检索主题 | 用户提供的研究方向；只有关键词时按关键词填写 |
| 检索词 | 实际使用的关键词、查询式及必要的扩展词 |
| 筛选条件 | 年份、文献类型、作者、机构等实际条件；未指定时写未限定 |
| 排序方式 | 相关度 / 被引量 / 时间；区分用户要求与实际执行，未满足时说明 |
| 检索日期 | 实际检索日期，YYYY-MM-DD；优先使用用户时区 |
| 结果数量 | 实际获取的候选数、去重后纳入数；不是全库命中数 |
| 数据通道 | 知网直连 → 已授权浏览器 → 公开 API → 公开网页中实际执行的过程与结果 |
| 未完成项 | 登录、验证码、摘要、全文、知网被引次数等；无未完成项时写无 |

表格后输出一行互斥的核验数量汇总，覆盖全部纳入论文，每篇仅按最终核验状态计一次：

知网已核验：N篇｜期刊官网已核验：N篇｜公开元数据已核验：N篇｜仅搜索线索：N篇

知网已核验合计详情页与检索页两种状态。只有线索时不得计入已核验。知网失败、以公开来源补充时，明确提示：公开来源结果不等同于知网检索结果。

## 二、检索结果

仅使用以下八列主表，不再输出十五列宽表。论文标题链接到可打开的真实来源；无法获得链接时保留纯文本并在卡片中说明。编号在主表、单篇卡片和综合分析中保持一致。

| # | 论文标题 | 作者 | 来源 | 年份 | 引用量（来源） | 核验状态 | 证据范围 |
|---|---|---|---|---|---|---|---|
| 1 | [论文标题](真实详情链接) | 已核验作者 | 期刊或原始文献来源 | 发表年份 | 已核验数字（来源） | 最终核验状态 | 全文 / 摘要 / 元数据 |

- 核验状态只能使用：`知网详情页已核验`、`知网检索页已核验`、`期刊官网已核验`、`公开元数据已核验`、`仅搜索线索，未完成详情核验`。
- 证据范围只能使用 `全文`、`摘要` 或 `元数据`，以实际阅读范围为准；获得全文链接不代表已阅读全文。
- 引用量写成 `数字（知网）`、`数字（Crossref）`、`数字（OpenAlex）`。同篇多个来源的数量用分号并列，不求和、不相互替代。不得把非知网数量标成知网被引。
- 缺失字段写 `未显示`，受阻字段写 `无法访问`，期刊专属字段对非期刊文献写 `不适用`。不得把未知引用量写成0或编造年份。
- DOI、卷期页、日期、刊号及来源明细移到单篇卡片，不从报告中删除。按被引量排序时采用统一来源口径；无法统一时说明，不把异源计数混为同一排名。
- 无纳入论文时保留表头，不创建占位论文，表下写 `未获得可核验或可追溯的论文条目。`

## 三、单篇论文解读

按结果编号为每篇纳入论文输出一张卡片。固定使用以下三级标题、加粗分组名及项目符号；完整引用仍放在该篇卡片底部，不集中到文末。

### 1.《论文标题》

**基本信息**

- 作者：已核验作者；主表使用“等”时，此处展示全部已获取作者
- 文献类型：期刊论文 / 学位论文 / 会议论文等原始类型
- 来源：期刊、学校、会议等原始文献来源
- 年卷期页：实际年份、卷、期、页码；分别标明缺失字段
- 发表日期：原始日期，不把只有年份的数据补成具体月日
- CN刊号：已核验值 / 未显示 / 无法访问 / 不适用
- ISSN：已核验值 / 未显示 / 无法访问 / 不适用
- DOI：已核验值 / 未显示 / 无法访问
- 核验状态：与结果表一致
- 证据范围：与结果表一致
- 元数据来源：逐项列出实际来源；多来源时说明各自核验的字段
- 检索时间：实际检索日期或时间
- 详情链接：实际来源链接；多个核验链接可分别列出

**内容解读**

- 研究问题：基于可访问内容概括
- 方法与数据：基于可访问内容概括
- 核心结论：基于可访问内容概括
- 价值与启示：基于证据提出的启示；推论需显式标明
- 局限：论文说明的局限；自行评议需标明为评议

**证据声明**

- 全文：写 `本总结基于已阅读的论文全文。`；仅阅读部分正文时说明阅读范围，未读章节不推断。
- 摘要：写 `本总结基于论文摘要，不代表对全文的完整解读。`
- 仅元数据：将整个“内容解读”分组替换为 `摘要或全文不可访问，暂不生成论文内容总结。`；证据声明写 `仅核验元数据，未读取摘要或全文。`
- 方法、样本、局限等在可访问内容中未出现时，对应项目写 `可访问内容未说明`，不补造信息。
- 实际输出选择上述适用声明，不输出全部条件说明。

**推荐引用（GB/T 7714）**

输出该论文完整引用，编号与结果表一致，不仅输出编号。期刊格式：`[1] 作者. 论文标题[J]. 期刊名称, 年, 卷(期): 页码.`；其他文献采用对应类型格式，不一律标[J]。必要引用字段缺失时写 `引用信息不完整` 并说明缺失项；不编造卷期页或作者。用户指定其他引用样式时使用其指定样式。

无纳入论文时不生成卡片，写 `暂无可解读的论文。`

## 四、跨论文综合

仅在至少两篇相关论文具有可访问摘要或全文时生成分析。只纳入有内容证据的论文，不依据题名或元数据推断共识、分歧或研究空白。

### 主题对比

| 研究方向 | 代表论文 | 主要方法 | 主要发现 | 主要不足 |
|---|---|---|---|---|
| 基于内容归纳的方向 | 论文编号与短题名 | 有证据的方法 | 有证据的发现 | 作者报告的不足或明确标注的评议 |

### 综合判断

- 共识：说明依据的论文编号；未形成共识时如实说明
- 分歧：区分结论冲突与样本、方法、条件不同；无证据时写未识别到可确认的分歧
- 研究空白：只描述本次可访问文献范围内的不足，不断言全领域无人研究
- 后续研究建议：标明为基于上述证据提出的建议

### 优先阅读

使用有序列表推荐最多3篇具有摘要或全文证据的论文，每项包含题名、编号及具体理由；可用论文不足3篇时按实际数量推荐，不凑数。

证据不足时保留第四部分标题，不输出对比矩阵或综合结论，写 `当前只有元数据或单篇可用摘要/全文，证据不足，暂不生成跨论文综合。`；无结果时写 `未获得论文内容证据，暂不生成跨论文综合。`
